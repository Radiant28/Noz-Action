# Nozdor Action 0.3.16

Камера за плечом, прицел, предварительное выделение NPC с выбором по ЛКМ и взаимодействие с NPC, почтой и лутом по назначенной клавише. Все настройки находятся в **Интерфейс → Модификации → Nozdor Action**. Команда **`/nfa`** открывает ту же панель.

## Установка и обновление

1. Полностью закрой игру: `/reload` не обновляет DLL. Этот выпуск содержит **аддон и DLL 0.3.16**, протокол 9. Для исправления ЛКМ и наведения замени оба компонента и запусти игру заново, даже если версия 0.3.13/0.3.14 уже установлена.
2. Скопируй **всё содержимое архива** в папку, где лежит `WoW.exe`, с объединением папок и заменой файлов предыдущей версии Nozdor Action. Аддон уже лежит в `Interface/AddOns/NozdorAction`; отдельно переносить его или запускать установщик не нужно.
3. Запусти **`Start-NozdorAction.cmd`** из папки игры. Он запускает `client-prototype/bin/NozdorActionLauncher.exe` с правильным расположением DLL.
4. В игре открой `/nfa`. На клиенте `ruRU` меню, назначения клавиш, подсказки, сообщения и состояния будут на русском автоматически. Для других языков используется английский. Проверь **DLL: 0.3.16**.
5. Назначь клавиши **Переключение**, **Взаимодействие**, **Клавиша курсора** кнопками **Задать режим**, **Задать действие**, **Задать курсор**. После входа режим выключен — включи его назначенной клавишей.

В корне архива находятся `Interface`, `client-prototype`, `Start-NozdorAction.cmd` и инструкции. `WoW.exe`, аккаунты и SavedVariables в архив не включены; личные настройки не заменяются. Короткая инструкция — `NozdorAction-Install.ru.txt`.

## Софт-таргет и выбор по ЛКМ

По умолчанию включена настройка **«Софт-таргет: выбор цели по ЛКМ»** в меню модификации (внизу панели). Наведение прицела использует штатное выделение `mouseover`; прицел окрашивается по предварительной цели, включая цвета классов. Основная цель от одного наведения не меняется. Под прицелом подсвечиваются также почтовые ящики, руда и другие доступные игровые объекты. Для игроков и NPC включается штатный эффект наведения; цвета классов прицела сохраняются.

В режиме управления камерой нажми **ЛКМ**, чтобы выбрать подсвеченную цель. Клик только выбирает: разговор, почта и лут открываются назначенной клавишей **«Взаимодействие»**. Выбранная цель остаётся при отведении прицела и кликах в пустоту; следующий клик по другой доступной цели сменит её. Проверяются дальность выбора и доступность объекта. Задержка автовыбора и флажок сохранения цели относятся к прежнему автоматическому режиму.

При свободном курсоре, освобождённом ПКМ, ЛКМ взаимодействует с NPC, доступным лутом и игровыми объектами под самим курсором, независимо от флажка софт-таргета. Клики по интерфейсу и Cell не превращаются в выбор под прицелом. Отключи софт-таргет, чтобы вернуть прежний автовыбор. Взаимодействие ЛКМ при свободном курсоре доступно в обоих режимах. Общий флажок выбора под прицелом должен быть включён.

При полном выключении режима сохраняются штатный ЛКМ и наведение WoW. Перехватчик наведения устанавливается только для активного софт-таргета с управлением камерой; при свободном курсоре или паузе возвращается исходный вызов клиента. При выключении режима также восстанавливается оконный обработчик (если его не обернул другой аддон). Привязки мыши не изменяются.

Если штатный ЛКМ не выбирает цель даже при выключенном режиме, проверь назначение `BUTTON1`: действие `NONE` отключает его. Штатное действие — `CAMERAORSELECTORMOVE`. Модификация не переназначает его автоматически и не меняет сочетания Cell.

## Управление

- **Переключение** — включает или выключает режим. По умолчанию F6, если она свободна и другая клавиша ещё не назначена. Только эта клавиша меняет состояние режима; сброс настроек и команды `/nfa toggle` / `/nfa off` его не меняют.
- **Esc** — работает обычным образом: закрывает окна, отменяет действия, открывает меню. Открытые окна временно освобождают курсор и приостанавливают автовыбор; после закрытия управление возобновляется.
- **Клавиша курсора** — по умолчанию удержание освобождает мышь, отпускание возвращает управление камерой. Если включён флажок **Курсор по нажатию**, одно нажатие освобождает курсор до следующего нажатия. Отпускать кнопку в этом режиме можно. По умолчанию клавиша ALT; после переназначения Alt больше не освобождает курсор. Положение камеры за плечом сохраняется.
- **Взаимодействие** — одна общая клавиша для NPC, почты и лута под прицелом. Один запрос при отпускании клавиши; удержание не повторяет запрос каждый кадр. Если уже открыто окно разговора, задания, торговца, тренера, почты, лута, банка, аукциона, текста предмета или такси, следующее нажатие сначала закрывает это окно штатным вызовом клиента. Новый запрос взаимодействия при закрытии не отправляется. В чате, настройках и при выключенном режиме окна не закрываются этой клавишей. Наведение само по себе не открывает разговор, торговлю или лут.

Все три действия доступны в **Назначение клавиш → Nozdor Action**. Для курсора выбери строку **Свободный курсор**, нажми поле первой или второй привязки и затем нужную клавишу или кнопку мыши. Средняя кнопка — `BUTTON3`, боковые — `BUTTON4` и `BUTTON5`. Они доступны также для включения режима и взаимодействия. Колёсико вверх/вниз и левая кнопка не поддерживаются для курсора.

**ПКМ для переключения курсора:** в `/nfa` нажми **«ПКМ: переключать курсор»** под назначениями клавиш. Эта кнопка включает `BUTTON2` и режим переключения одним нажатием. Первое нажатие освобождает курсор, второе возвращает mouse look. Можно также ввести `BUTTON2` или сочетание вроде `CTRL-BUTTON2` в поле **«Клавиша курсора»**. Для ПКМ используется отдельный нативный путь: привязки «Свободного курсора» в обычном меню снимаются, остальные действия WoW не переназначаются. Штатная обработка ПКМ сохраняется при выключенной модификации.

Пока открыты сумки, настройки и другие поддерживаемые окна, ПКМ не включает mouse look и не меняет выбранное состояние курсора. Нажатия ПКМ по элементам открытого интерфейса проходят в игру; ПКМ по миру за окном блокируется. Состояние окон передаётся DLL на каждом кадре. После закрытия окна восстанавливается прежнее состояние курсора.

В 0.3.12 добавлена поддержка новых окон NOZDOR — `SettingsPanel` и `AuctionHouseFrame` — и панелей, действительно открытых через оконный менеджер. Повторное взаимодействие с открытой почтой закрывает также все сумки, включая сумки ElvUI через штатный `CloseAllBags`. Закрытие остальных диалогов отдельно не закрывает сумки.

**Свободный курсор, ЛКМ и Cell (0.3.11).** Если курсор освобождён через ПКМ, ЛКМ по NPC, почте или другому доступному объекту мира выполняет обычное взаимодействие по месту курсора. Работает и при удержании ПКМ с выключенным «Курсор по нажатию», и при переключении. ЛКМ по фреймам Cell, панелям и кнопкам интерфейса остаётся кликом интерфейса; при открытых сумках, настройках и других блокирующих окнах взаимодействие с миром не выполняется. Ctrl/Shift/Alt не сбрасывают освобождённый курсор; обычная привязка `BUTTON2` работает и с уже удерживаемым модификатором. Явное сочетание, например `CTRL-BUTTON2`, проверяется при начале нажатия. Служебная удерживаемая ПКМ убирается из передаваемых клиенту событий мыши и логического состояния потока, чтобы сочетания вроде Ctrl+ЛКМ не превращались в Ctrl+ПКМ+ЛКМ. Сам Cell и его привязки не изменяются. При свободном курсоре новые нажатия ПКМ по интерфейсу в режиме переключения передаются интерфейсу.

Панель `/nfa` и стандартное меню используют одни привязки: изменение в одном месте отражается в другом. Для курсора поддерживаются, например, `F8`, `CTRL-F8`, `SHIFT-BUTTON4`, `CTRL-SHIFT-BUTTON5`, буквы, цифры, F1–F24, основные служебные клавиши и NumPad. При обычном переназначении первая клавиша заменяется, вторая сохраняется. Пустое поле снимает обе привязки действия; для курсора это также отключает резервный Alt. Назначение заменяет прежнее действие этой клавиши WoW. Эти привязки меняются вне боя.

Прежние отдельные `ALT`, `SHIFT`, `CTRL`, `LALT` и аналогичные модификаторы можно задать в `/nfa`; они также работают по флажку **Курсор по нажатию**, но не отображаются обычной привязкой WoW. Такой выбор убирает обе обычные привязки курсора. По умолчанию или при переносе старых настроек остаётся прежняя клавиша; назначение в стандартном меню получает приоритет. После явного снятия привязок резервная клавиша сама не возвращается. Отмена временного изменения в стандартном окне сохраняет исходную настройку.

Сумки, NPC, банк, аукцион, почта, лут, настройки, основные стандартные панели и подтверждения освобождают курсор. Учтены окна аддонов из `UISpecialFrames`, включая сумки и банк ElvUI. Управление возвращается после закрытия последнего окна. Служебные панели RefinedBlizzPlates больше не вызывают постоянную паузу, появившуюся в 0.3.1.

Смерть, такси, транспорт, потеря фокуса и загрузка мира также временно приостанавливают работу. После входа или `/reload` режим первоначально выключен.

Нажатие взаимодействия само по себе не освобождает курсор. Он появляется, когда действительно открыто окно NPC, почты или лута, либо нажата назначенная клавиша курсора. Автовыбор цели после взаимодействия приостанавливается на 200 мс без снятия захвата мыши.

## Настройки

- **Правое плечо / Левое плечо** и **Смещение за плечо** (0–3) — сторона и величина смещения. Старое отрицательное смещение переносится на левую сторону.
- **Расстояние камеры** (3–25) и **Высота камеры** (от −1 до 3) — базовое положение. Стены ограничивают смещение.
- **Курсор в центре прицела** — при освобождении мыши курсор появляется в центре прицела. Если флажок снят, возвращается к предыдущему свободному положению. Перемещение выполняется один раз, затем мышь свободна.
- **Курсор по нажатию** — сохраняет свободный курсор после отпускания клавиши; следующее нажатие возвращает управление камерой. Открытие окон и потеря фокуса не сбрасывают это состояние; нажатия в меню, чате и неактивном окне его не меняют. Выключение режима камеры, загрузка мира и смена способа управления курсором сбрасывают состояние. По умолчанию используется удержание.
- **Подстройка камеры на маунте**, **Маунт: + расстояние** (0–15, по умолчанию 3) и **Маунт: + высота** (0–5, по умолчанию 1) — плавное отдаление и подъём при посадке, возврат после спешивания.
- **Штатная камера: пешком / Штатная камера: маунт** — независимый выбор обычного положения камеры для каждого режима. Дополнительное смещение за плечо и заданный модулем зум не применяются; прицел, автовыбор и назначенные действия продолжают работать. Если камера уже была смещена модулем, возвращается сохранённый при включении зум. Колесо и штатные изменения камеры WoW остаются доступны.
- **Отдельная камера на маунте** — включает собственные **Расстояние на маунте** (3–40), **Высота на маунте** (от −1 до 8), **Смещение на маунте** (0–5) и **Маунт: левое плечо**. Переход между собственными положениями сглаживается, стены ограничивают смещение. По умолчанию этот профиль выключен. Приоритет на маунте: штатная камера → отдельный профиль → прежняя адаптация с добавочным расстоянием/высотой.
- **Автовыбор NPC под прицелом** — выбор доступного для обычного выделения дружественного, нейтрального, враждебного NPC, другого игрока или трупа существа. Свой персонаж исключён. Почтовые ящики, сундуки, двери и декорации обычного таргета не поддерживают; их действие доступно по клавише взаимодействия.
- **Сохранять цель до следующей** — если включено, уход прицела с существа не снимает выбранную цель. Следующая допустимая цель выбирается с обычной задержкой. Если выключено, автоматически выбранная цель снимается через 250 мс после потери прицелом. По умолчанию выключено. Эта настройка не включает взаимодействие или лечение.
- **Дальность выбора** (5–300 ярдов, по умолчанию 40) и **Задержка смены цели** (0–500 мс, по умолчанию 100) — дальность автовыбора и подтверждение новой цели. Для выбора на 200–300 ярдов подними ползунок в `/nfa`; сохранённые значения не меняются. Фактический выбор ограничен наличием объекта в клиенте и штатным наведением. На дальность способностей и взаимодействия настройка не влияет.
- **Размер прицела / Непрозрачность прицела** — размер 8–64 и прозрачность. В нижней части панели доступны **Предыдущая форма / Следующая форма**: разорванный крест, плюс, точка, круг, круг с точкой, квадрат, ромб и уголки. **Толщина прицела** имеет восемь уровней; вместе с размером меняет вид обводки и точки. Все формы сохраняют цвет цели/класса. Коллекция использует одну текстуру `Reticles.tga`, включённую в архив.
- **Цвет прицела по цели** — включено по умолчанию. Игроки окрашивают прицел в цвет класса из стандартной таблицы WoW или пользовательских цветов классов. Для NPC: враждебный — красный, нейтральный — жёлтый, дружественный — зелёный. Мёртвая цель — серая, отсутствие цели — белый цвет. Цвет соответствует текущему таргету, включая сохранённый после ухода прицела. Если флажок снять, прицел всегда белый.
- **Сброс камеры** — исходное правое плечо, расстояние 6, смещение 1.25, высота 0.65 и параметры маунта; штатные режимы и отдельный профиль маунта выключаются. **Сброс всех настроек** также возвращает разорванный крест, толщину 3, отключает сохранение цели и возвращает резервный ALT; привязки стандартного меню сохраняются. Режим от сброса не включается.

Панель прокручивается. Параметры и прежний режим отдельного модификатора хранятся в SavedVariables; обычные привязки всех трёх действий — в настройках WoW.

## Совместимость и диагностика

Поддерживается конкретный x86 WoW.exe 3.3.5a build 12340:

```text
SHA-256 c33f54116161b0baf3d6f3b58276688336e96c50a80e921f10a8d5a6c38a4a60
```

Один номер 12340 не гарантирует совместимость другого EXE. Лаунчер проверяет файл, DLL — PE и 78 диапазонов кода в памяти. Исходный EXE не изменяется. Лаунчер создаёт новый процесс и загружает DLL; для запуска без модификации выйди из игры и запусти обычный WoW.exe.

`Start-NozdorAction.cmd --check` проверяет совместимость без запуска игры. Можно также запускать `client-prototype/bin/NozdorActionLauncher.exe` с явным путём к WoW.exe.

`/nfa status` выводит состояние и последнюю проверку прицела. Журнал — `client-prototype/bin/NozdorAction.log`; он заменяется при загрузке DLL. Переданная команда взаимодействия ещё не означает успешное выполнение на сервере. Дальность, состояние и стандартные ограничения взаимодействия проверяет сам клиент. При включённом штатном автоподходе он может начать движение к объекту.

Графические ошибки лаунчера переводятся при русском языке интерфейса Windows. Технический журнал DLL, консольная диагностика лаунчера и числовые поля проверки прицела остаются на английском.

## Проверки и сборка

Работа 0.2.2 подтверждена пользователем. Все девять автоматических проверок 0.3.16 прошли: математика и выбор/сохранение цели, настоящий x86 CALL hook с откатом, аддон на английском/русском/резервном языке, проверки EXE, отказ DLL в чужом процессе и загрузка DLL в приостановленный тестовый процесс. Дополнительно проверяются профили камеры и их приоритет, закрытие диалогов и все 64 координатных ячейки прицелов. Генератор текстуры проверяет силуэты, толщину, прозрачные поля, сглаживание и TGA. Host-тесты используют Lua 5.4 с mock API, а не WoW Lua 5.1 и secure UI.

Для разработчика: `client-prototype/Build.ps1` собирает проект; `client-prototype/Install-Addon.ps1` обновляет установленный аддон с резервной копией. `client-prototype/tools/generate_reticles.py` воспроизводит текстуру прицелов и PNG-предпросмотр с самопроверками. Нужны x86 GCC/CMake/Ninja, Python и установленная тестовая lua54.dll. Для установки из архива эти инструменты не нужны.

После сборки запусти `python client-prototype/tools/package_release.py`. Скрипт проверяет переводы и форматные параметры, содержимое ZIP, готовое расположение аддона, распаковку и запуск перемещённого лаунчера/корневого CMD с `--check`. Поддерживаемый EXE копируется только в тестовую папку, в архив он не входит.

В игре ещё требуется проверить новые функции, русские шрифты и переносы строк при разных масштабах интерфейса. Подробности — `client-prototype/VERIFICATION.md`. Возможны конфликты с другими расширениями; правила и античит конкретного сервера не проверялись.
