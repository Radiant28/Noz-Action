Nozdor Action 0.3.14 — установка

1. Полностью закрой игру.
2. Скопируй ВСЁ содержимое архива в папку, где находится WoW.exe.
   Подтверди объединение папок Interface и client-prototype и замену файлов
   предыдущей версии Nozdor Action. Перекладывать аддон отдельно не нужно.
3. Запусти Start-NozdorAction.cmd из папки игры.
4. В игре открой /nfa или Интерфейс → Модификации → Nozdor Action.
   На русском клиенте меню будет на русском автоматически.
5. Назначь клавиши «Переключение», «Взаимодействие» и «Клавиша курсора».
   Нажми «Задать режим», «Задать действие» и «Задать курсор» соответственно.
   Режим при входе выключен. Включи его назначенной клавишей.
   По умолчанию переключение — F6, если она свободна; курсор — ALT.

Курсор теперь доступен также в меню «Назначение клавиш» → Nozdor Action →
«Свободный курсор». Там можно выбрать первую и вторую клавиши,
среднюю кнопку мыши (BUTTON3), боковые BUTTON4/BUTTON5 и сочетания, например
SHIFT-BUTTON4. Панель /nfa показывает те же привязки. Пустое поле с кнопкой
«Задать курсор» снимает обе привязки и отключает резервную клавишу.

В /nfa есть флажок «Сохранять цель до следующей»: цель не снимается при уходе
прицела; следующая цель выбирается наведением. По умолчанию флажок выключен.

«Курсор по нажатию» позволяет нажать и отпустить кнопку: мышь остаётся
свободной до следующего нажатия. Без флажка нужно удерживать клавишу.

«Цвет прицела по цели»: игроки — цвет класса; NPC — красный / жёлтый /
зелёный по отношению к персонажу; мёртвые — серый; без цели — белый.

Повторная клавиша взаимодействия закрывает уже открытое окно NPC, почты,
лута и другие окна взаимодействия, не отправляя нового запроса.

Прокрути настройки ниже: «Форма прицела и камера на маунте».
Там доступны восемь форм, восемь толщин и отдельные штатные камеры
для пешего режима и маунта. «Отдельная камера на маунте» задаёт собственные
расстояние, высоту и сторону плеча. Штатная камера сохраняет прицел.

Клавиша курсора освобождает мышь согласно флажку «Курсор по нажатию».
NPC выбирается наведением прицела. Разговор, почта и лут — только по клавише
взаимодействия. Открытые сумки и окна интерфейса временно освобождают курсор.

После копирования рядом с WoW.exe должны лежать:
  Start-NozdorAction.cmd
  Interface\AddOns\NozdorAction\NozdorAction.toc
  Interface\AddOns\NozdorAction\Localization.lua
  Interface\AddOns\NozdorAction\NozdorAction.lua
  Interface\AddOns\NozdorAction\Bindings.xml
  Interface\AddOns\NozdorAction\Reticles.tga
  client-prototype\bin\NozdorActionLauncher.exe
  client-prototype\bin\NozdorAction.dll

WoW.exe в архив не включён и не заменяется. Личные настройки сохраняются.
В архиве аддон 0.3.14 и DLL 0.3.13 (протокол 9).
При обновлении с 0.3.13 достаточно заменить аддон и выполнить /reload. Для замены DLL полностью закрой игру.
При управлении камерой софт-таргет подсвечивает объект, ЛКМ только выбирает цель.
Для действия под прицелом используй назначенную клавишу взаимодействия.
При освобождённом ПКМ курсоре ЛКМ взаимодействует с объектом под курсором в обоих режимах.
В меню модификации можно отключить софт-таргет и вернуть прежний автовыбор.
