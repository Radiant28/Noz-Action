# Nozdor Action

Камера из-за плеча, прицел и взаимодействие одной клавишей для **WoW 3.3.5a, build 12340**.

**Текущая версия: 0.3.20, тестовая.** Проект состоит из x86 DLL, лаунчера и Lua-аддона. Работает на стороне клиента, исходный `WoW.exe` не изменяет. В комплекте аддон 0.3.20 и DLL 0.3.20, протокол 12.

## Возможности

- Камера от правого или левого плеча с настройкой высоты, расстояния и смещения.
- Адаптация камеры на маунте и отдельный профиль для верховой езды.
- Независимый выбор штатной камеры с прицелом пешком и на маунте.
- Подсветка под прицелом для игроков, NPC, почты, руды и других доступных игровых объектов.
- Софт-таргет по умолчанию: при управлении камерой наведение подсвечивает объект, ЛКМ выбирает основную цель без взаимодействия. При свободном курсоре ПКМ + ЛКМ взаимодействует с объектом под курсором.
- Наведение и выбор по штатным неймплейтам и их дочерним полоскам, без зависимости от аддона оформления и без требования C_NamePlate. ЛКМ в пустое место сбрасывает цель.
- Прежний автовыбор доступных игроков и NPC можно вернуть в настройках. Дальность выбора 5–300 ярдов.
- В софт-режиме выбранная цель сохраняется при отведении прицела. В автоматическом режиме доступны сохранение цели и задержка смены.
- Общая назначаемая клавиша для NPC, почты и доступного лута. Повторное нажатие закрывает окно взаимодействия и сумки, включая заранее открытый стандартный рюкзак без ElvUI.
- Назначаемая клавиша свободного курсора, режим удержания или переключения, поддержка ПКМ, средних и дополнительных кнопок мыши.
- Восемь форм прицела, настройка размера, толщины и прозрачности, окраска по отношению цели и классу игрока.
- Пауза управления при открытии поддерживаемых окон интерфейса, русский и английский языки.
- В выключенном режиме восстанавливаются штатный оконный обработчик и наведение; при свободном курсоре используется исходный обработчик подсветки игроков, NPC и объектов.

Автовыбор не применяет способности и не взаимодействует автоматически. Объект должен быть доступен клиенту и системе наведения. Настройка дальности не увеличивает дальность способностей и взаимодействия.

## Установка готовой сборки

Этот репозиторий содержит исходники. Готовый архив создаётся командой упаковки ниже. В 0.3.20 изменены и аддон, и DLL. После обновления нужен полный перезапуск игры.

1. Полностью закрой WoW: `/reload` не обновляет DLL.
2. Распакуй содержимое `NozdorAction-0.3.20.zip` прямо в папку с `WoW.exe` с объединением папок.
3. Запусти `Start-NozdorAction.cmd`.
4. Открой `/nfa` или «Интерфейс → Модификации → Nozdor Action».
5. Назначь клавиши и включи режим. По умолчанию используется F6, если она свободна; после входа и `/reload` режим выключен.

Подробные параметры: [руководство пользователя](client-prototype/README.ru.md).

## Совместимость

Поддерживается конкретный x86 клиент с SHA-256:

```text
c33f54116161b0baf3d6f3b58276688336e96c50a80e921f10a8d5a6c38a4a60
```

Один номер сборки 12340 не гарантирует совместимость другого EXE. Лаунчер проверяет файл, DLL проверяет 78 диапазонов кода. Игровые файлы, аккаунты, настройки пользователя, логи и резервные копии в репозиторий не входят.

## Сборка на Windows

Требуются PowerShell, Python 3, CMake, Ninja и **32-битный MinGW GCC**. Для тестов аддона нужен x86 Lua 5.4: текущий тестовый загрузчик ожидает `C:\mingw32\bin\lua54.dll`.

1. Склонируй репозиторий:

   ```powershell
   git clone https://github.com/Radiant28/Noz-Action.git
   cd Noz-Action
   ```

2. Для генерации проверок и тестов помести совместимый `WoW.exe` в корень клона, рядом с этим README. Он исключён из Git и дистрибутива. Для сборки и проверок запускать игру не требуется.

3. Добавь инструменты в PATH и выполни сборку:

   ```powershell
   $env:PATH = 'C:\mingw32\bin;' + $env:PATH
   .\client-prototype\Build.ps1
   ```

   Скрипт проверяет исходный клиент, генерирует сигнатуры, собирает DLL и лаунчер в `client-prototype/bin`, затем запускает CTest.

4. Создай архив для установки в игру:

   ```powershell
   python .\client-prototype\tools\package_release.py
   ```

   Результат — `client-prototype/NozdorAction-0.3.20.zip` с готовой структурой `Interface/AddOns`, DLL, лаунчером и стартовым CMD. Упаковщик проверяет содержимое и перемещаемость запуска. Повторная упаковка той же версии не перезаписывает существующий архив и проверочную папку.

Текстура прицелов уже включена в исходники; её можно пересоздать:

```powershell
python .\client-prototype\tools\generate_reticles.py
```

`Install-Addon.ps1` предназначен для рабочей копии, находящейся непосредственно в папке клиента: он устанавливает аддон в `Interface/AddOns` в корне репозитория и сохраняет резервную копию прежних файлов.

## Структура

|---|---|
| `client-prototype/src` | DLL, лаунчер, камера, выбор цели и проверки совместимости |
| `client-prototype/addon/NozdorAction` | Аддон, локализация, назначения клавиш и текстура прицелов |

## Проверки и обратная связь

Для 0.3.20 пройдены **10 автоматических проверок** (включая установленный RefinedBlizzPlates; без этого аддона — 9). Нативные проверки охватывают захват мыши, клики и очередь выбора цели; Lua-тесты используют mock API и не заменяют проверку внутри WoW. Последние исправления камеры и курсора требуют подтверждения в игре.

Подробности: [VERIFICATION.md](client-prototype/VERIFICATION.md). Сообщения об ошибках: [Issues](https://github.com/Radiant28/Noz-Action/issues). Укажи версию, шаги воспроизведения и вывод `/nfa status`; перед публикацией логов проверь их содержимое.

В 0.3.20 тип объекта определяется по дескриптору, поэтому почта и руда подсвечиваются и при попадании типа 2. Окраска софт-цели получает отношение и класс по GUID. Дополнительная поправка цветов союзников RefinedBlizzPlates 1.12.0 и инструкция лежат в `client-prototype/compat`.
